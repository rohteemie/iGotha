# iGotha Frontend

Welcome to the iGotha frontend application! This is a modern React-based chat application built with real-time messaging capabilities.

## 📋 Documentation

For a comprehensive development roadmap from planning to deployment, please see:
- [**Frontend Development Roadmap**](./ROADMAP.md) - Complete guide covering all phases of frontend development

## 🚀 Quick Start

Coming soon! The frontend is currently in the planning phase. Please refer to the [ROADMAP.md](./ROADMAP.md) for the complete development plan.

## 🛠 Technology Stack

- **React** - UI library
- **Redux Toolkit** - State management
- **Socket.io-client** - Real-time communication
- **React Router** - Client-side routing
- **Material-UI / Ant Design** - UI components

## 📂 Project Structure

```
frontend/
├── src/
│   ├── api/              # API service layer
│   ├── components/       # Reusable UI components
│   ├── features/         # Feature-based modules
│   ├── hooks/            # Custom React hooks
│   ├── pages/            # Page components
│   ├── redux/            # Redux store and slices
│   ├── routes/           # Route configuration
│   └── utils/            # Utility functions
└── public/               # Static assets
```
